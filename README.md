# WellnessPath - Holistic Wellness Journey Platform

A blockchain-based platform for tracking holistic wellness journeys and celebrating milestone achievements. WellnessPath provides transparent progress tracking while incentivizing sustained wellness practices through automated reward systems.

## Features

- **Journey Tracking**: Record and verify holistic wellness progress
- **Pathway Certification**: Wellness facilitators certify approved wellness pathways
- **Milestone Celebration**: Automated rewards for wellness achievements
- **Progress Transparency**: Immutable record of all wellness journey activities

## Getting Started

### Prerequisites
- Clarinet CLI installed
- Stacks wallet for wellness journey participation

### Installation
\`\`\`bash
git clone https://github.com/your-org/wellnesspath
cd wellnesspath
clarinet check
\`\`\`

### Usage
1. Launch wellness program with designated facilitator
2. Certify approved wellness pathways
3. Record wellness progress in certified pathways
4. Claim milestone rewards based on journey achievements

## Smart Contract Functions

### Public Functions
- `launch-wellness-program`: Initialize the wellness journey tracking system
- `certify-pathway`: Approve wellness pathways for progress tracking
- `record-wellness-progress`: Log wellness activities and progress achievements
- `calculate-vitality-celebrations`: Calculate available celebration reward pool
- `claim-wellness-rewards`: Claim rewards based on wellness journey progress

### Read-Only Functions
- `get-wellness-progress`: View participant's total wellness progress
- `get-participant-pathway`: Get participant's primary wellness pathway
- `get-total-wellness-progress`: View total community wellness progress
- `is-pathway-certified`: Check if wellness pathway is certified
- `get-wellness-stats`: View overall program statistics
